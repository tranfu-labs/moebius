# 官网首页

## 页面目标

让第一次接触 Moebius 的访客快速理解“把整个开发团队装进一次对话”的产品定位，看到团队选择、会话推进和对话分析三个核心能力，并能下载当前稳定的 Apple Silicon macOS 版本或查看 GitHub 源码。

首页面向全世界正在用 AI 提效的普通专业者，因此英文是默认语言，中文是并列的完整语言版本，而不是附属翻译页。访客不该为了看懂产品主张先去找语言开关。

## 用户场景

面向正在使用本地 AI CLI、希望把开发目标交给多角色 Agent 团队推进的 Mac 用户。访客可能从分享链接、GitHub 或产品介绍进入，母语可能是中文，也可能不是。

## 入口与去向

首页是公开官网根路径，提供英文与简体中文两个语言版本：根路径是英文页，`/zh/` 是中文页。两页内容一一对应，可以互相到达。页内导航进入三个能力段；GitHub 操作前往 `tranfu-labs/moebius` 仓库或 Releases；下载操作前往当前最新稳定 Release 的 Apple Silicon DMG。

## 区域与信息

- 页头提供品牌、三段能力锚点、更新日志、语言切换、GitHub 与下载入口。
- 语言切换在页头右上角，展开后同时列出英文与简体中文，并标出当前语言。它是页面上唯一的语言入口，不在页脚或正文重复。
- 首屏用一句核心主张、简短定位和真实桌面端预览建立产品心智。产品预览截图按语言取用同语言的界面截图——英文页里的产品界面必须是英文，中文页里必须是中文。
- 宣言段强调用户只需与 Leader Agent 对齐目标。
- 三个能力段依次解释团队匹配、会话内推进和对话分析。
- 对照段用同一道题的两份真实产物说明单 Agent 与团队的差别：先给出题目原文，再并排展示「一个 Agent」与「两个 Agent」各自的产出，两份产物都用同一模型跑出、直接内联在页面里可以自己看。对照段只呈现产物本身，不给出评分、名次或任何质量数字。
- 最终行动段重复下载与源码入口，页脚回收产品定位和平台范围。

## 操作与反馈

- “团队 / 对话 / 分析”平滑滚动到对应能力段，并随桌面端滚动位置标记当前段。
- “更新日志”打开 GitHub Releases；“GitHub / 查看 GitHub 源码”打开公开仓库。
- 下载按钮默认可到达最新稳定 Release 页面；页面可成功取得 GitHub 最新 Release 数据时，直接指向名称以 `-mac-arm64.dmg` 结尾的 DMG 资产。
- 外部链接在新标签页打开，并使用安全的 `rel` 属性。
- 语言切换选择另一种语言时，在当前标签页进入对方语言页的同一位置，并记住这次选择。
- 访客第一次打开根路径且此前没有选过语言时，按浏览器首选语言决定落点：中文进入 `/zh/`，其余留在英文页。跳转是替换式的，浏览器「后退」回到访客的来源页，而不是在两个语言页之间弹跳。
- 已经显式选过语言的访客，之后再打开根路径一律按自己的选择落地，浏览器语言不再干预。
- `/zh/` 不因浏览器语言自动跳回英文页：分享出去的中文链接对任何访客都必须打开中文内容。

## 页面状态

- 默认：所有正文、产品预览和核心链接可见。
- 语言默认：访客未选过语言且浏览器语言不是中文时，落在英文页。
- 语言推断为中文：访客未选过语言且浏览器语言是中文时，落在中文页。
- 语言已选定：无论浏览器语言如何，落在访客选定的语言页。
- 语言记忆不可用（隐私模式或存储被禁用）：显示当前路径对应的语言，不跳转环路、不空白。
- 下载解析成功：下载按钮直接下载当前稳定 Apple Silicon DMG。
- 下载解析失败或受限：下载按钮仍进入最新稳定 Release 页面，不显示伪造或失效的资产地址。
- 减少动态效果：取消非必要动画，内容与链接保持完整。

## 弹层与危险操作

不适用。首页没有弹层、数据写入或不可逆操作；下载由 GitHub 承载。

## 响应式与窗口行为

桌面端以粘性能力叙事配合产品示意；900px 以下降级为纵向顺序阅读。页面不得产生横向滚动，移动端仍可使用下载与 GitHub 主操作。页头在约 375px 视口下必须单行容纳品牌、语言切换与下载入口；次要入口可以在窄视口隐藏，下载入口不可以。

## 关联流程

不适用。当前官网是单页静态入口，不承载登录、注册或应用内流程。

## 指标与验收

- 根路径与 `/zh/` 都直接返回完整单页 HTML，产品预览和品牌图标资源均可加载。
- 首屏、三个能力段与最终行动段在两个语言版本下都完整可读。
- 单个语言版本内不出现另一语言的残留：可见文案、标题、社交分享文案、图片替代文本、无障碍标签和产品预览截图全部是该语言。
- GitHub 仓库、Releases 和下载后备链接均指向 `tranfu-labs/moebius`。
- 所有购买/下载相关位置明确仅支持 Apple Silicon Mac。
- 约 375px 视口无页面级横向滚动，减少动态效果时内容不缺失。

## 非目标

不在官网实现账号登录、在线工作台、服务端 API、邮箱收集、Windows/Linux/Intel Mac 下载或产品文档站。

语言上只提供英文与简体中文两个版本，不做繁体中文或其他语种；不做服务端语言协商，也不把语言策略托管给某个具体静态托管平台的重定向规则。
