# 官网首页

> 2026-08-16 更新：01 段主题从「我们预置了很多团队」改为「团队来源开放」。收敛到一支内置团队后，原来的三条卖点（开箱即用的开发／文案／增长、每一个需求都有对应最专业的团队、按需求匹配推荐）全部失去支撑——被承诺的品类里有两个已经不存在，剩下这一支也撑不起「每一个需求」。改写后的说法是收敛后唯一还站得住的那一个，而且它比原来的承诺更大：不是我们备了几支，是任何人做的都能装。

## 页面目标

让第一次接触 Moebius 的访客快速理解“把整个开发团队装进一次对话”的产品定位，看到团队来源、会话推进和对话分析三个核心能力，并能下载当前稳定的 Apple Silicon macOS 版本或查看 GitHub 源码。

首页面向全世界正在用 AI 提效的普通专业者，因此英文是默认语言，中文是并列的完整语言版本，而不是附属翻译页。访客不该为了看懂产品主张先去找语言开关。

## 用户场景

面向正在使用本地 AI CLI、希望把开发目标交给多角色 Agent 团队推进的 Mac 用户。访客可能从分享链接、GitHub 或产品介绍进入，母语可能是中文，也可能不是。

## 入口与去向

首页是公开官网根路径，提供英文与简体中文两个语言版本：根路径是英文页，`/zh/` 是中文页。两页内容一一对应，可以互相到达。页内导航进入三个能力段；GitHub 操作前往 `tranfu-labs/moebius` 仓库或 Releases；下载操作前往当前最新稳定 Release 的 Apple Silicon DMG。

## 区域与信息

- 页头提供品牌、三段能力锚点、更新日志、语言切换、GitHub 与下载入口。
- 语言切换在页头右上角，展开后同时列出英文与简体中文，并标出当前语言。它是页面上唯一的语言入口，不在页脚或正文重复。
- 首屏用一句核心主张、简短定位和真实桌面端预览建立产品心智。产品预览截图按语言取用同语言的界面截图——英文页里的产品界面必须是英文，中文页里必须是中文。
- 宣言段强调用户只需与 Leader Agent 对齐目标。
- 三个能力段依次解释团队来源、会话内推进和对话分析。
- 01 段解释团队从哪里来。它主动交代产品只带一支内置团队，再说明其余团队来自 GitHub、任何人都能发布一支。主动说出访客装完就会自己发现的事，是这一段唯一有效的可信手段；遮掩没有收益，因为从九支砍到一支这件事本身瞒不住。
- 01 段的示意图必须体现团队来源，不能再画「从若干支预置团队里挑一支」——图和文讲的是同一件事，否则访客信图不信字。
- 01 段末尾有一条文字出口「看看一支团队是怎么做的」，指向面向作者的团队仓库约定文档，不是搜索结果页。topic 下当前只有产品自己的仓库，把读者送进一个几乎空的搜索页会当场推翻这一段刚说过的话；而约定文档回答的正是访客读完「谁都能发一支」之后的下一个问题——怎么做。
- 出口是文字链，不与「下载 macOS 版」竞争位置。**下载为主，GitHub 出口为次**：没装 App 的访客去 GitHub 看团队没有意义，团队只能在 App 里装。出口是「下载之后你还能做什么」的补充。
- 对照段用同一道题的两份真实产物说明单 Agent 与团队的差别：先给出题目原文，再并排展示「一个 Agent」与「两个 Agent」各自的产出，两份产物都用同一模型跑出、直接内联在页面里可以自己看。产物之后把两次运行画在同一条时间轴上：每一步是轴上一段，长度就是它真实占的时间，一眼能看出两次总长相同、切分不同；每条轴末尾给出用时、花费与生成 token 的合计。点任意一步展开这一步的角色、用时、往返与工具调用次数、花费，以及这个 Agent 在这一步写下的每一条消息原话——带时间、未经编辑、保持它当时工作的语言；只把它贴进对话的产物源码折叠起来并标明折叠了多少。原话旁边可以配一句本页语言的概述，但概述看得出是概述，不冒充原话。复核那一步另外列出它把题面拆成的条目和核对手段。步骤切换不依赖 JavaScript，也能用键盘操作。记录里的数字都来自这两次运行的会话日志，花费是 token 按公开 API 价目折算，页面说明来源与口径，并说明一道题跑两次是个例而不是基准测试。对照段只呈现产物和运行记录本身，不给出评分、名次或任何质量数字。
- 最终行动段重复下载与源码入口，页脚回收产品定位和平台范围。

## 01 段定稿文案

英文是默认语言，因此先定英文；中文是并列的完整版本，不是译文。两版说的是同一件事，各自在自己的语言里成立。

| 位置 | 英文 | 中文 |
| --- | --- | --- |
| 主标题 | `We ship one team.` | 我们只带一支团队。 |
| 副标题 | `Teams come from GitHub — including the ones you make.` | 团队从 GitHub 来，包括你自己做的那支。 |
| 卖点 1 | `Anyone can publish one` — your team, in a public repo, findable by everyone | **谁都能发一支**——把你的团队放进公开仓库，所有人都搜得到 |
| 卖点 2 | `You read it first` — the full prompt for every member, before it runs on your machine | **你先读**——每名成员的完整提示词，在它跑上你的机器之前 |
| 卖点 3 | `Updates come from the author, not from us` — install once, keep getting their changes | **更新来自作者，不是我们**——装一次，之后一直收到他的改动 |
| 出口 | `See how a team is made` | 看看一支团队是怎么做的 |

写作时守住的三条约束：

- **只承诺能力，不暗示生态已经存在。** `moebius-team` topic 下当前只有产品自己的仓库，任何「其余的团队在 GitHub 上」「剩下的从 GitHub 装」之类的说法字面就是假的——不存在「其余的」。能说的只有「任何人都能做一支放上去，你能装任何人做的」。
- **鼓励行动的句子不能说过头。** 卖点 1 曾写成「一支团队就是一个打了 topic 的仓库」，读者照做只打个 topic 就发布，发出来的是装不上的仓库，代价落在第三方身上。改成「放进公开仓库，所有人都搜得到」，具体格式留给出口后面的约定文档。
- **不承诺一份还没写的文档有多长。** 出口曾有一版写「团队的格式，一页说完」，约定文档写出来超过一页这句就成假话；「看看一支团队是怎么做的」不含这个风险，而且正好接住卖点 1 留下的问题。

主标题不承担信息完整性，它只制造一个必须往下读的悬念——一个具体数字比任何形容词更能停住眼睛，而且访客必然想知道下一行怎么圆。副标题承担翻转：`Teams come from GitHub` 给出的是新规则，团队的来源不是我们。

## 操作与反馈

- “团队 / 对话 / 分析”平滑滚动到对应能力段，并随桌面端滚动位置标记当前段。
- “更新日志”打开 GitHub Releases；“GitHub / 查看 GitHub 源码”打开公开仓库。
- 01 段的「看看一支团队是怎么做的」打开团队仓库约定文档。它与页头、首屏、页脚的 GitHub 入口一样归属 `tranfu-labs`，访客不会被带到另一个身份下。
- 下载按钮默认可到达最新稳定 Release 页面；页面可成功取得 GitHub 最新 Release 数据时，直接指向名称以 `-mac-arm64.dmg` 结尾的 DMG 资产。
- 外部链接在新标签页打开，并使用安全的 `rel` 属性。
- 语言切换选择另一种语言时，在当前标签页进入对方语言页的同一位置，并记住这次选择。
- 访客第一次打开根路径且此前没有选过语言时，按浏览器首选语言决定落点：中文进入 `/zh/`，其余留在英文页。跳转是替换式的，浏览器「后退」回到访客的来源页，而不是在两个语言页之间弹跳。
- 已经显式选过语言的访客，之后再打开根路径一律按自己的选择落地，浏览器语言不再干预。
- `/zh/` 不因浏览器语言自动跳回英文页：分享出去的中文链接对任何访客都必须打开中文内容。

## 页面状态

- 默认：所有正文、产品预览和核心链接可见。
- 语言默认：访客未选过语言且浏览器语言不是中文时，落在英文页。
- 语言推断为中文：访客未选过语言且浏览器语言是中文时，落在中文页。
- 语言已选定：无论浏览器语言如何，落在访客选定的语言页。
- 语言记忆不可用（隐私模式或存储被禁用）：显示当前路径对应的语言，不跳转环路、不空白。
- 下载解析成功：下载按钮直接下载当前稳定 Apple Silicon DMG。
- 下载解析失败或受限：下载按钮仍进入最新稳定 Release 页面，不显示伪造或失效的资产地址。
- 减少动态效果：取消非必要动画，内容与链接保持完整。

## 弹层与危险操作

不适用。首页没有弹层、数据写入或不可逆操作；下载由 GitHub 承载。

## 响应式与窗口行为

桌面端以粘性能力叙事配合产品示意；900px 以下降级为纵向顺序阅读。页面不得产生横向滚动，移动端仍可使用下载与 GitHub 主操作。页头在约 375px 视口下必须单行容纳品牌、语言切换与下载入口；次要入口可以在窄视口隐藏，下载入口不可以。

## 关联流程

不适用。当前官网是单页静态入口，不承载登录、注册或应用内流程。

## 指标与验收

- 根路径与 `/zh/` 都直接返回完整单页 HTML，产品预览和品牌图标资源均可加载。
- 首屏、三个能力段与最终行动段在两个语言版本下都完整可读。
- 01 段在两个语言版本下都按上表定稿文案呈现，且不出现任何暗示「已有很多团队可选」的说法；示意图体现团队来源，不再画从多支预置团队里挑选。
- 01 段的出口指向团队仓库约定文档且可访问；该文档不存在或不可达时，这一段不上线——出口是死链比少一条出口更糟。
- 官网不出现具体的内置团队数量之外的团队清单，也不陈列可安装的第三方团队。
- 单个语言版本内不出现另一语言的残留：可见文案、标题、社交分享文案、图片替代文本、无障碍标签和产品预览截图全部是该语言。
- GitHub 仓库、Releases 和下载后备链接均指向 `tranfu-labs/moebius`。
- 所有购买/下载相关位置明确仅支持 Apple Silicon Mac。
- 约 375px 视口无页面级横向滚动，减少动态效果时内容不缺失。

## 非目标

不在官网实现账号登录、在线工作台、服务端 API、邮箱收集、Windows/Linux/Intel Mac 下载或产品文档站。

不在官网做团队搜索、团队陈列、团队市场或安装入口。团队只能在 App 里装，官网的任务是让访客相信这条路存在且不难，行动交给下载。

语言上只提供英文与简体中文两个版本，不做繁体中文或其他语种；不做服务端语言协商，也不把语言策略托管给某个具体静态托管平台的重定向规则。
