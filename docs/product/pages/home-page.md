# 官网首页

## 页面目标

让第一次接触 Moebius 的访客快速理解“把整个开发团队装进一次对话”的产品定位，看到团队选择、会话推进和对话分析三个核心能力，并能下载当前稳定的 Apple Silicon macOS 版本或查看 GitHub 源码。

## 用户场景

面向正在使用本地 AI CLI、希望把开发目标交给多角色 Agent 团队推进的 Mac 用户。访客可能从分享链接、GitHub 或产品介绍进入。

## 入口与去向

首页是公开官网根路径。页内导航进入三个能力段；GitHub 操作前往 `tranfu-labs/moebius` 仓库或 Releases；下载操作前往当前最新稳定 Release 的 Apple Silicon DMG。

## 区域与信息

- 页头提供品牌、三段能力锚点、更新日志、GitHub 与下载入口。
- 首屏用一句核心主张、简短定位和真实桌面端预览建立产品心智。
- 宣言段强调用户只需与 Leader Agent 对齐目标。
- 三个能力段依次解释团队匹配、会话内推进和对话分析。
- 最终行动段重复下载与源码入口，页脚回收产品定位和平台范围。

## 操作与反馈

- “团队 / 对话 / 分析”平滑滚动到对应能力段，并随桌面端滚动位置标记当前段。
- “更新日志”打开 GitHub Releases；“GitHub / 查看 GitHub 源码”打开公开仓库。
- 下载按钮默认可到达最新稳定 Release 页面；页面可成功取得 GitHub 最新 Release 数据时，直接指向名称以 `-mac-arm64.dmg` 结尾的 DMG 资产。
- 外部链接在新标签页打开，并使用安全的 `rel` 属性。

## 页面状态

- 默认：所有正文、产品预览和核心链接可见。
- 下载解析成功：下载按钮直接下载当前稳定 Apple Silicon DMG。
- 下载解析失败或受限：下载按钮仍进入最新稳定 Release 页面，不显示伪造或失效的资产地址。
- 减少动态效果：取消非必要动画，内容与链接保持完整。

## 弹层与危险操作

不适用。首页没有弹层、数据写入或不可逆操作；下载由 GitHub 承载。

## 响应式与窗口行为

桌面端以粘性能力叙事配合产品示意；900px 以下降级为纵向顺序阅读。页面不得产生横向滚动，移动端仍可使用下载与 GitHub 主操作。

## 关联流程

不适用。当前官网是单页静态入口，不承载登录、注册或应用内流程。

## 指标与验收

- 生产入口直接返回单页 HTML，产品预览和品牌图标资源均可加载。
- 首屏、三个能力段与最终行动段完整可读。
- GitHub 仓库、Releases 和下载后备链接均指向 `tranfu-labs/moebius`。
- 所有购买/下载相关位置明确仅支持 Apple Silicon Mac。
- 约 375px 视口无页面级横向滚动，减少动态效果时内容不缺失。

## 非目标

不在官网实现账号登录、在线工作台、服务端 API、邮箱收集、Windows/Linux/Intel Mac 下载或产品文档站。
