# 线框：support-claude-cli

本 change 只改变 onboarding 第 1 步的一张状态卡：从两行扩为三行。步骤数、标题、
footer、AI 建队和后续页面布局不变。

## 宽窗口：三种状态并存

```text
┌────────────────────────────────────────────────────────────┐
│  Moebius                         首次启动                   │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                  第 1 步，共 4 步                          │
│                      环境准备                              │
│   Codex、Claude Code 或 Kimi 至少一个可用，就可以启动团队   │
│                                                            │
│    ┌────────────────────────────────────────────────┐     │
│    │  ✓  Codex CLI      可用 · 已登录 · 真实版本    │     │
│    ├────────────────────────────────────────────────┤     │
│    │  !  Claude Code    已安装 · 需要登录           │     │
│    │      请在终端运行 claude，登录后重新检查       │     │
│    ├────────────────────────────────────────────────┤     │
│    │  ✕  Kimi CLI       未安装                      │     │
│    │      官方 Kimi 安装命令                    [▶] │     │
│    └────────────────────────────────────────────────┘     │
│                                                            │
├──────────────── 固定 footer ──────────────────────────────┤
│                            [ 重新检查 ] [ 继续 ]           │
└────────────────────────────────────────────────────────────┘
```

断言：

- 三行使用同一 status-row 组件和等宽内容边界，不为 Claude 建特殊卡；
- 至少一行 ready，故“继续”可用；
- needs-login 行没有安装按钮，missing 行才有；
- 真实版本只来自 runtime DTO，线框、Storybook 默认态不写示例版本。

## 宽窗口：三个安装任务

```text
┌────────────────────────────────────────────────────────────┐
│  Moebius              ◌ 3 项 CLI 正在安装…     首次启动   │
├────────────────────────────────────────────────────────────┤
│                  第 1 步，共 4 步                          │
│                      环境准备                              │
│    ┌────────────────────────────────────────────────┐     │
│    │  ◌ Codex CLI      installing              […] │     │
│    ├────────────────────────────────────────────────┤     │
│    │  ◌ Claude Code    downloading             […] │     │
│    ├────────────────────────────────────────────────┤     │
│    │  ◌ Kimi CLI       verifying               […] │     │
│    └────────────────────────────────────────────────┘     │
├──────────────── 固定 footer ──────────────────────────────┤
│                        [ 重新检查 ] [ 继续（灰置） ]       │
└────────────────────────────────────────────────────────────┘
```

聚合入口点击后显示同一任务列表；某项结束时数量从 3 变 2/1，不能按“另一项”写死。

## 窄窗口

```text
┌──────────────────────────────┐
│ Moebius          首次启动    │
├──────────────────────────────┤
│ 第 1 步，共 4 步             │
│ 环境准备                     │
│ 三种 CLI 至少一个可用即可继续│
│ ┌──────────────────────────┐ │
│ │ ✓ Codex CLI             │ │
│ │   可用 · 已登录          │ │
│ ├──────────────────────────┤ │
│ │ ! Claude Code           │ │
│ │   已安装 · 需要登录      │ │
│ │   登录后重新检查         │ │
│ ├──────────────────────────┤ │
│ │ ✕ Kimi CLI              │ │
│ │   未安装             [▶]│ │
│ └──────────────────────────┘ │
│                              │
├──────────────────────────────┤
│       [重新检查] [继续]      │
└──────────────────────────────┘
```

断言：

- 行内主状态和辅助文本允许换行，CLI 名称与状态图标不被压缩隐藏；
- 页面不产生横向滚动；主体过高时只有步骤主体纵向滚动，固定 footer 不遮挡第三行；
- 安装、取消、重新检查和继续都可键盘到达；状态变化由 `aria-live` 宣告；
- `prefers-reduced-motion` 只移除旋转/位移动画，不移除阶段文本。
