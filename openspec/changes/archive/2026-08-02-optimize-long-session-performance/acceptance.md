# 验收清单：optimize-long-session-performance

> 这是实现完成后的可核查记录。真实运行证据只保留脱敏计数、枚举、耗时、布尔结果和脱敏标识；不在仓库写入用户正文、完整 session 对象、session id、本机绝对路径或临时证据路径。

## 性能与传输

- [x] **热切换，普通 → 长**：在真实 Electron 中从侧栏进入普通会话再切换到长会话，重复 15 次；以点击到页面稳定可交互为 click-to-settled，p50 目标 ≤ 1.05 s、p95 目标 ≤ 1.15 s。结果：p50 559 ms、p95 619 ms；基线约 1,291/1,336 ms。
- [x] **热切换，长 → 普通**：同样重复 15 次并记录 p50/p95。结果：p50 429 ms、p95 479 ms，满足同一预算。
- [x] **冷进入，普通 → 长**：在真实 Electron 中进行一次独立冷启动观察；点击到页面稳定可交互约 621.4 ms，低于单次预算 1.50 s。该结果不是 p50/p95。
- [x] **冷进入，长 → 普通**：在真实 Electron 中进行一次独立冷启动观察；点击到页面稳定可交互约 353.8 ms，低于单次预算 1.50 s。该结果不是 p50/p95。
- [x] **空闲轮询**：同一会话保持打开连续 5 秒；每次 state 刷新均为 304、响应体 0 bytes，timeline DOM mutation = 0，React commit = 0。
- [x] **活动运行变化**：同一会话保持打开时，`elapsedMs`、`liveMarkdown`、活动摘要和终态变化继续以现有频率更新；变化响应为 200，不命中 unchanged 短路。逻辑层、定向测试和活动运行记录覆盖该契约；真实 provider 额度受限下未新增独立 provider 重跑，列为低风险剩余观察。

## 数据与窗口化

- [x] **消息口径**：对账 store = 211、API = 143、内部 placeholder = 68，其中 `211 = 143 + 68`；143 条公开消息全部可访问，68 条 placeholder 不进入时间线 DOM。
- [x] **DOM 规模**：长会话由约 10,635 个 DOM 节点降至约 883，初始窗口只挂载视口附近约 9 条消息；逻辑消息数量不减少。
- [x] **动态高度**：包含多种 Markdown、代码块和换行高度的真实消息，窗口在高度变化后仍保持可滚动和可定位；验收覆盖 8 类动态高度。
- [x] **首尾滚动**：从页面入口滚到第一条、最后一条公开消息，首尾均可见且没有错误跳位。
- [x] **未挂载 Relay**：将目标消息置于当前窗口外，从目录轨激活后，页面先挂载目标再精确定位；不落到近似消息。
- [x] **中段阅读恢复**：停在会话中段后切换到另一会话再返回，恢复原阅读位置；期间新消息不强制跳到末尾。
- [x] **最新消息跟随**：停在末尾时新消息继续跟随；离开末尾阅读历史时不被新消息夺走位置。

## 失败恢复与诊断边界

- [x] **普通导航失败**：真实 Electron 中目标加载失败后，selection、主内容标题/路由、右栏 visibility、host、tabs 文档、active tab、草稿和阅读位置逐项与失败前相等，并显示可理解反馈。
- [x] **Hosted 分析导航失败**：App 行为测试覆盖 hosted 目标失败或过期；原 route、active tab、visibility、host tabs 文档、草稿和阅读位置恢复，目标写入的 tabs 不残留。该路径由行为测试承担，真实 Electron 本轮未单独调用 hosted provider。
- [x] **成功导航提交一次**：普通、搜索和 hosted 成功路径只呈现目标现场，不出现短暂回滚后再前进。
- [x] **正常运行无探针**：不带性能 query 启动真实 Electron；页面不挂载 Profiler，运行时不存在 `window.__MOEBIUS_TIMELINE_PERF__`。显式验收 query 仅用于受控诊断，不属于正式运行时接口。
