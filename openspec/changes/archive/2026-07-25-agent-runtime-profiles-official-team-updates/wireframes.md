## pages/main-conversation.md

基线是 `docs/product/pages/main-conversation.md#团队按钮展开`。本 change 不增加执行引擎
选择器；会话仍只选择团队，并说明已开始会话不会被团队页后续修改。

```text
   ┌──────────────────────────────────────┐
   │ ✓ 开发团队                           │
   │   营销团队                           │
   │ ──────────────────────────────────── │
   │ 这段对话沿用载入时的团队状态，        │
   │ 之后在团队页的修改不影响它            │
   └──────────────────────────────────────┘
```

legacy 旧会话也使用这句不虚构 CLI/model/effort 字段的中性说明。onboarding、
invalid-profile 创建/换队 gate 与右侧完整过程继续范围外，不在本页新增状态或按钮。
