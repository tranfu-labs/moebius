# 验收清单：sidebar-chat-session-analysis

本清单供功能验收与视觉验收使用。每条用户可见行为都包含页面入口和可断言信号；程序状态以运行事实与 DOM/接口结果判断，不以对话中的“通过”等自然语言判断。

## Page Story 人工闸门

- [x] A01 打开 Storybook `Page/Console/SessionAnalysis/AnalysisDraftSingleFragment`；主内容仍是来源会话，右侧是与普通新对话同布局的会话，附件位置出现一个可删除“文本片段 1”，聚焦或悬浮可读完整静态文本。
- [x] A02 打开 `AnalysisDraftAccumulatedFragments`；两个片段在同一附件行，候选问题位于新对话空态，正文与项目/工作空间/团队控件仍为普通新对话样式。
- [x] A03 在 A02 用键盘激活候选问题；输入框正文变为对应完整提示词，片段内容和上下文选择不变。
- [x] A04 打开 `CreatedSidebarConversation`；右侧内容使用普通已有会话时间线、运行记录和 composer，不出现分析标题栏、分析状态徽标或第二套布局。
- [x] A05 打开 `RightSidebarZeroTabs`；右侧栏关闭，主内容显示按钮可聚焦；重新打开后显示“这个标签要看什么”，没有高亮或伪造“新标签”。
- [x] A06 打开 `RecoveredSidebarConversation`；左侧只高亮 sidebar chat 行，主内容显示来源会话，右侧显示目标会话，两个会话状态点互不复制。
- [x] A07 打开 `SourceUnavailableFallback`；sidebar chat 在主内容区按普通会话显示，并有非阻断“暂时无法回到来源会话”说明。

## 真实运行功能验收

- [x] F01 在主会话活动 run 的更多菜单选择「分析当前对话」；右侧栏打开/聚焦未发送会话，出现由可信端点返回的静态文本胶囊，来源 run 继续运行。
- [x] F02 在同一来源与初始工作空间的另一个位置再次触发入口；标签数不增加，原草稿新增下一枚胶囊并获得焦点。
- [x] F03 删除一枚胶囊后首次发送；创建请求与首条 JSONL 用户消息只包含仍保留的片段，被删文本不进入 prompt。
- [x] F04 胶囊存在但正文和普通附件均为空时发送按钮不可用；加入正文后可发送，标题由正文生成。
- [x] F05 首次发送时改选项目、实际工作空间和团队；创建后的 session summary、cwd 与团队快照等于最终选择，不继承来源运行配置。
- [x] F06 首次创建失败；右侧仍保留正文、片段、普通附件、上下文和焦点；重试成功后只创建一个 session 和一条首条用户消息。
- [x] F07 首次发送成功；当前 tab id/位置不变但 locator 从 draft 变为 session，左侧最终项目下新增普通会话行。
- [x] F08 已创建会话点击完整输出、文件链接和子任务；目标出现在同一个外层右侧栏的兄弟标签，不出现嵌套 sidebar。
- [x] F09 关闭有内容或最终上下文偏离系统预选的草稿；显示丢弃确认。取消保持原样，确认后该草稿不再恢复。
- [x] F10 关闭最后一个标签；标签数为零且右侧栏关闭。重新显示右侧栏只出现内容选择，不自动创建 tab。
- [x] F11 关闭未选中/选中 tab；未选中时当前内容不变，选中时优先右邻再左邻，键盘焦点落在新 tab 按钮。
- [x] F12 手动从内容选择创建普通 sidebar chat 并保留「通用助手」；首条请求使用普通写策略，不要求先确认方案。
- [x] F13 从「分析当前对话」创建会话并改选另一团队；首次诊断 run 仍为只读，团队身份不绕过写入闸门。
- [x] F14 在确认前要求 Agent 修改工作空间、团队文件或其他本地目标；Codex/Kimi 均不产生持久变化，时间线显示先给方案并等待确认的说明。
- [x] F15 对当前方案给出模糊、否定、局部或过期确认；没有 write lease，不执行持久命令，并在会话中说明仍需确认的范围。
- [x] F16 明确自然语言确认当前方案；同一会话同一 Agent identity 获得一次写入执行，完成后 lease 关闭，输出报告实际改动与验证。
- [x] F17 Agent 改写方案后沿用旧确认；runtime 拒绝旧版本，保持只读并要求确认新方案。
- [x] F18 来源会话运行期间确认并修改；两段会话可以并行，应用不自动停止来源，也不把来源运行配置或状态点复制给 sidebar chat。
- [x] F19 文本指向的数据根记录超出当前 Agent 普通读取范围；Agent 如实说明不可读，应用不提升 read roots 或复制记录。
- [x] F20 从左侧点击已创建 sidebar chat；来源可用时只高亮目标行并恢复“来源主内容 + 右侧目标”，焦点落在目标 tab。
- [x] F21 已打开组合的来源被归档或移除；目标原地迁移到主内容并保留阅读位置、草稿、运行状态与选中态，成功后才清理旧 tab。
- [x] F22 来源外部失效且迁移失败；保持最后成功内容和目标选中态并显示重试，不留下空主内容或重复 tab。
- [x] F23 单条或项目批量归档 sidebar chat；所有 host 标签组删除目标 tab，未归档兄弟 tab 的顺序与阅读位置不变，失败时整体回滚。
- [x] F24 搜索完整会话标题；trim + NFKC + lowercase 后包含匹配能找到活动 sidebar chat，空查询不请求也不列出全部。
- [x] F25 搜索中改变关键词/归档范围并让旧请求晚到；页面只呈现当前控件对应的最近结果，旧请求不覆盖也不阻塞新搜索。
- [x] F26 对归档 sidebar chat 激活「恢复并打开」；会话只恢复一次，来源可用走组合路由，来源失效走主内容降级，失败保持搜索现场。
- [x] F27 输入法组合期间按 Enter；只确认候选词且搜索按钮不可用，组合结束后再次提交才搜索。
- [x] F28 两支团队合法重名；新对话、sidebar chat 与已有会话团队菜单的可见文本和辅助名称均可稳定区分，且不显示内部 key、路径或临时序号。
- [x] F29 从只有既有官方团队的安装升级；恰好新增一支官方「通用助手」，唯一 `@assistant` 使用 `Codex / gpt-5.6-sol / high`，不覆盖现有团队。
- [x] F30 官方身份或预定目录冲突；产品内保留动作失败不改变现有团队/文件，重试成功后恰好新增一支可辨认官方团队。
