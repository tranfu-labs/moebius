# Wireframes：remove-new-conversation-readiness-hint

## 基线

页面事实源与结构基线：`docs/product/pages/main-conversation.md#新对话从项目行进入项目已带上`、`docs/product/pages/main-conversation.md#选择工作空间与团队`。

本 change 不改路由、composer 或上下文控件，只删除 composer 下方的 readiness 准备提示区。

## pages/main-conversation.md

### 变更前：新对话可能追加准备提示

```text
┌──────────────────────────────────────────────────────────┐
│ 新对话                                                   │
│                                                          │
│                  今天想推进什么？                        │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 描述你的目标…                                      │  │
│  │ [项目] [工作空间] [分支] [团队]              [发送]│  │
│  └────────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────────┐  │
│  │ ! 其中 3 名成员仍需完成 Codex / Kimi 准备…         │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

### 变更后：上下文后直接结束，无准备概念

```text
┌──────────────────────────────────────────────────────────┐
│ 新对话                                                   │
│                                                          │
│                  今天想推进什么？                        │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 描述你的目标…                                      │  │
│  │ [项目] [工作空间] [分支] [团队]              [发送]│  │
│  └────────────────────────────────────────────────────┘  │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

checking、ready、missing、needs-login、unavailable、IPC 延迟或失败均使用同一变更后结构。真实 CLI 启动失败发生在消息已经提交后的会话时间线，不在新对话页预告或预检。
