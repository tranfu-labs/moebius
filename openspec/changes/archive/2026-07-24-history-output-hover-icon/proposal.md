# 提案：history-output-hover-icon

## 需求基线

| 文件 | 小节 | 变更 | 状态 |
| --- | --- | --- | --- |
| `docs/product/pages/main-conversation.md` | 时间线 · 运行中的操作条 · 验收 #11 | 成功历史消息的完整输出入口保留原位左对齐，改为 hover/focus 才显示的图标按钮 | 已写入 |

## 背景

主时间线当前在每条带 run id 的 Agent 历史消息正文下方常驻一个「完整输出」`ghost` 文字按钮。入口满足了步骤结束后仍可追溯完整过程的要求，但重复文字控件挤占消息间距，并把低频证据入口呈现成正文后的常驻操作。

用户确认入口不应移动到右侧：它继续位于正文下方、与正文左边界对齐，只把呈现收敛为悬停或键盘聚焦时出现的图标按钮。

## 提案

- 主时间线成功 Agent 历史消息保留既有 `sessionId + runId` 打开过程标签的行为。
- 把正文下方的 `ghost` 文字按钮替换为 24px 文件图标按钮，保持当前左对齐位置。
- 图标默认视觉隐藏；悬停整条消息、消息内获得焦点或按钮自身键盘聚焦时显示。
- 保留 `aria-label="完整输出"` 与原生悬停说明，确保图标没有可见文字时仍可理解、可键盘操作。
- 活动运行、四种异常事实和子任务标签不在本次范围内。

## 影响

- 修改 `packages/console-ui/src/console/operator-console.tsx` 及共置测试，并把历史消息轻操作模式登记到 `packages/console-ui/DESIGN.md`。
- 修改主会话 PRD 与 `console-ui` 行为规格。
- 不改变右侧栏过程标签、输出读取接口、run 定位契约或任何运行时数据。
