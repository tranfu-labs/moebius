## pages/main-conversation.md

### 丰富团队菜单与历史快照身份

```text
┌ 当前对话 · 开发团队（旧名）             官方来源 ┐
│ 负责软件方案、实现、测试与复核                     │

│ [开 开发经理·主] [开 开发] [测 测试] [+1]          │
├────────────── 切换到其他团队 ──────────────────────┤
│ 通用助手                               官方来源     │
│ 处理一般对话与任务                                  │
│ 主 Agent：通用助手 · 1 名成员                       │
│ [通 通用助手·主]                                    │
├────────────────────────────────────────────────────┤
│ 这段对话沿用当前已载入的团队状态                    │
└────────────────────────────────────────────────────┘
```

顶部当前项来自 effective snapshot，团队改名后仍显示历史身份。`+N` 在当前项内展开有界完整名单，不选择团队也不关闭菜单。

### 分类变化、等待与失败

```text
│ ℹ Agent 定义已更新 · 2 名成员                [应用] │
│ ℹ 运行配置已更新 · 1 名成员                  [应用] │
│ ℹ 团队信息已更新                             [应用] │
│ 任一“应用”都会载入整支团队最新保存的完整版本        │
┌────────────────────────────────────────────────────┐
│ 项目 A  默认工作空间  main  [开发团队 ▾]            │
│ 继续说点什么，或 @ 一个成员…                   ＋ ↑ │
└────────────────────────────────────────────────────┘
```

等待时三类合并为“当前工作结束后应用团队更新”，点击后消息留在现有待发射区并可编辑/移除。失败时保持原快照，原位提供“重试应用”和“取消应用并继续使用当前版本”。
