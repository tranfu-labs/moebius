## pages/main-conversation.md

主对话现有版式不增加预检卡片或弹窗。首次发送后的失败沿用已有“这一步没跑起来”记录：

```text
新对话

┌──────────────────────────────────────────────────────────────┐
│ [▱ 项目 A] [◇ 开发团队 ▾]                                   │
│                                                              │
│ 修复登录流程                                                 │
│                                                   [发送]      │
└──────────────────────────────────────────────────────────────┘

发送后

你 · 刚刚
┌──────────────────────────────────────────────────────────────┐
│ 修复登录流程                                                 │
└──────────────────────────────────────────────────────────────┘

开发经理 · 刚刚
┌──────────────────────────────────────────────────────────────┐
│ ⚠ 这一步没跑起来 · Kimi 未能启动                   [重试]    │
└──────────────────────────────────────────────────────────────┘
```

不新增“正在检查运行环境”中间态。团队选择区已有的“仍需完成 Codex/Kimi 准备”提示保持不变，只作参考且不阻止发送。
