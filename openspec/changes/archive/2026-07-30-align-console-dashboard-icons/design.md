# 设计：align-console-dashboard-icons

## 范围收紧结论

本 change 不做“全量统一”。生产几何只修改下表 4 组有直接参考或真实可见不一致证据的图标，
且不缩小任何既有按钮宿主；其他左侧栏与主会话图标仅补测试和真实窗口观察，不改尺寸、描边或布局。

| 生产组件 / 图标 | `dashboard.html` 对应或真实证据 | 生产改动 | 宿主 |
| --- | --- | --- | --- |
| `conversation-sidebar.tsx` 项目 disclosure | 参考 `.project-row .chev` 为 14px；真实 Electron 为 16px | 16→14px | 32px 行不变 |
| 同文件项目新建 / 更多 | 参考 `.project-actions` 为 13px；真实 Electron 为 16px，视觉重量明显大于 14px 项目 disclosure | 16→14px | 28×28 按钮不变 |
| 同文件会话更多 | 真实 Electron 为 16px / 24px，而同为 24px 高密度轻操作的消息工具为 14px，邻近视觉重量不一致 | 16→14px | 24×24 按钮不变 |
| `role-composer.tsx` `variant="main"` 主理人停止 | 参考同一 `.send-btn` 在发送/停止状态均使用同一图标盒；生产 main 添加/发送为 16px，停止为 14px | main 14→16px；embedded 保持 14px | main 32×32 按钮不变 |

选中会话的 `»` 是独立明确改动：删除该节点，但保留生产 `pl-7` 与参考 28px 标题缩进。

## 五项核对回应

1. `sub-session-card`、RunBlock、结果、异常、上下文和附件没有生产几何改动。它们已有直接匹配
   或结构不等价，只纳入测试和 Electron 观察。实际生产几何改动严格限于上表。
2. `packages/console-ui/DESIGN.md` 已有默认 16px / `strokeWidth={1.5}`、高密度 14px、状态
   12px / 2px 的设计事实。本 change 不全局改生产 stroke；只把参考页中有直接生产对应的现有
   SVG 作用域描边从 1.6 调到 1.5，状态图标继续 2px。
3. 不采用原方案的 24px 项目按钮宿主。项目新建/更多保留生产 28px 宿主，只校正内部图形为
   14px；会话更多保留 24px，Composer 保留 32px，因此点击目标不缩小。
4. 修订后不新增任何参考 DOM。“重新查看引导、会话更多、项目修复”代表状态全部取消；
   `dashboard.html` 只删除现有 `.sel-mark`，现有信息结构、假数据和交互脚本均不变。
5. 几何断言之外，参考页与真实 Electron 都增加人工观察记录：图标与文字基线是否自然，
   同一行相邻按钮的视觉重量是否均衡；这两项必须随 evidence 明确写出结论。

## 参考 HTML 同步

只修改现有 DOM / CSS：

- 侧栏关闭和主区顶栏开合图形 18→16，宿主仍 28；
- 项目操作宿主 22→28、图形 13→14；项目 disclosure 已是 14；
- 子会话入口 13→14，不改变卡片行结构；
- Composer 添加 / 发送图形 15→16，宿主仍 32；现有脚本切换的停止状态复用同一盒；
- 对直接对应生产角色的现有 SVG 使用作用域 `stroke-width: 1.5` 与 block 盒；不改 `.icon`
  全局默认，不改状态 2px 描边；
- 删除现有 `.sel-mark` 节点和样式；`.conv-row` 保持 28px 左 padding。

不新增“重新查看引导”、会话更多、项目修复或其他 DOM，不修改参考页假数据和交互脚本。

## 生产代码落点

- `conversation-sidebar.tsx`：项目 disclosure 14px；项目新建/更多 14px 且宿主仍 28px；
  会话更多 14px 且宿主仍 24px；删除 `»` 节点但保留 `pl-7`、状态尾列和 `aria-current`。
- `role-composer.tsx`：仅 `variant="main"` 的主理人停止改为 16px并保持 32px 宿主；
  `variant="embedded"` 的停止图形继续 14px，右侧栏几何不变。
- 其他组件不做生产几何改动。特别是 `operator-console.tsx`、`sub-session-card.tsx`、
  `run-block.tsx`、`run-outcome.tsx`、`result-card.tsx`、上下文和附件组件只补断言。

不创建通用 `Icon` 包装组件，不增加单枚 `top`、padding 或 transform 补偿。

## 验收设计

### 参考 HTML

在 Chromium 1400×900 打开 `dashboard.html`：

- 对现有 shell、导航、项目、消息工具、子会话、状态、上下文、附件和 Composer 逐组记录图形、
  宿主、描边与中心差；单行中心差 `≤0.5px`；
- hover 项目行后确认现有项目操作仍显示，28px 按钮在 32px 行内居中；
- 切换现有会话后确认 DOM 与可见文本均无 `.sel-mark`、`»`、`>>`，选中前后标题 x 与宽度不变；
- 人工观察并在 evidence 记录：各图标与所在文字基线自然；同一行相邻按钮视觉重量一致；
- 确认 DOM 数量、示例数据和脚本行为除移除选中标记外没有变化。

### 真实 Electron

扩展 `pnpm exec tsx scripts/acceptance/console-dashboard-ui.ts`：

- 对白名单 4 组断言目标图形尺寸和原宿主尺寸，对其余审计项记录既有几何而不要求改值；
- hover 项目/会话行，确认项目修复、新建、更多和会话更多仍可达；项目折叠状态保持；
- 切换选中会话，断言 DOM / 可见文本无 `»/>>`，标题 x 与宽度不变；
- 覆盖添加附件、发送、主理人停止和专业成员停止，确认回调、焦点、Tooltip 和状态变化不回归；
- 900×620、窄窗和 900×480 下继续断言无根级溢出、动态 Composer 与滚动边界不回归；
- 人工观察并在 evidence 记录：图标与文字基线自然；同一行相邻按钮视觉重量一致。

页面入口与可断言信号：

- 入口：默认验收命令与同命令 `--hold`；
- 信号：白名单尺寸、宿主尺寸、中心差、标题坐标、标记文本、hover/focus 可见性、折叠状态、
  附件数量、发送/停止状态、根滚动尺寸，以及人工视觉观察结论。

### 自动化门禁

- `ConversationSidebar`：白名单尺寸 class、选中/未选中 DOM、固定缩进、状态点、hover/focus、
  折叠、修复入口与操作回调。
- `RoleComposer`：main 停止 32/16、添加/发送既有 32/16，并明确断言 embedded 停止仍为 14px。
- `OperatorConsole`、RunBlock、RunOutcome、SubSessionCard、结果、上下文与附件：只做既有几何及
  交互防回归，不修改生产布局。
- Console UI 全量测试、typecheck、Storybook、Desktop build、真实 Electron 默认与 `--hold`、
  `git diff --check` 全绿后才能声明 code-verified。

## 权衡与风险

1. 保留所有生产点击宿主，避免用视觉密度调整换取更小点击目标。
2. 保留会话 28px 标题缩进，删除标记不回收其绝对定位区域，确保切换不横跳。
3. 不给参考页补缺失生产状态；参考页只证明已有对应角色，缺失角色由真实 Electron 证明。
4. `RoleComposer` 是共享组件；实现按 `variant` 只改 main 停止图形，并断言 embedded 继续 14px。
5. 参考页作用域描边规则必须精确命中现有对应 SVG，避免全局 `.icon` 改动波及 Logo 或状态图标。
