## 真实运行验收语句与证据归属

- [x] **[直接对齐参考稿] 收起态 / 常规窗口**：启动 `pnpm desktop`，打开一段至少含用户、主 Agent、两个专业成员最终回复的根会话；主会话左缘常驻参考稿尺寸的目录槽，普通横线与当前阅读横线形成明确长短 / 强弱层级，用户为前景色、各 Agent 保持稳定身份色。
  **自动证据**：组件测试断言 slot / 行 / 横线的尺寸、透明度、颜色来源和当前态；OperatorConsole 测试断言目录只在主会话。
  **独立视觉复核**：必须在真实桌面核对左缘留白、横线密度、身份色和当前态层级，构建成功不能替代。

- [x] **[直接对齐参考稿] 展开态 / 布局与键盘入口**：在同一页面分别用指针悬停目录行、再用键盘 Tab 聚焦目录事件；两种入口都让面板从左锚点向右展开为参考稿的抬升中性底、细描边和舒展行距，标题、正文、composer 与主时间线滚动位置不跳动。
  **自动证据**：组件测试分别触发 `mouseEnter` 与 `user.tab()`，断言 `data-expanded=true`、目标行保持真实 DOM focus、面板宽高 / 行高进入展开值且预览可见；OperatorConsole 测试断言宿主布局节点未重挂载、滚动值未变化。
  **独立视觉复核**：必须在真实桌面用鼠标和纯键盘各执行一次，核对左锚展开、行距、焦点可见性与正文零重排。

- [x] **[直接对齐参考稿] 展开态 / 轨迹视觉**：使用 `你 → 主 Agent → 开发 → 主 Agent → 测试 → 开发` 历史；用户节点位于固定主干，Agent 泳道按首次出现从左到右排列，成员色分支从前一事件平滑分叉、穿过同成员回复并在后一事件并回，当前阅读节点为空心描边环，不出现旧的全宽等距散点或逐相邻事件 S 线。
  **自动证据**：纯模型测试断言泳道顺序、主干 / 分支 path 数据、进入 / 并回端点和当前节点结构；组件测试断言 SVG 消费这些路径。
  **独立视觉复核**：必须核对曲线连续性、颜色归属、节点与线的对齐以及旧轨迹确已消失。

- [x] **[直接对齐参考稿] 展开态 / 图层与 hover**：横向移动到最左和最右事件行的任意空白处都能命中对应节点；hover band 位于轨迹下方、不遮线，当前事件关联轨迹加粗，其他轨迹仍清晰可见。
  **自动证据**：组件测试断言整行 hit target、band / path / button 图层顺序和检查事件对应的强调属性。
  **独立视觉复核**：必须核对空白处命中、hover 底色不盖线、强调轨迹不过亮且其余轨迹仍可读。

- [x] **[直接对齐参考稿] 预览与关闭**：从最左事件移到最右事件时，参考稿宽度的预览卡只沿纵向跟随并保持距整个面板固定间距；卡片显示作者、时间和有限行原文，不显示 `@slug` 或关联用户标题；指针跨过间隙进入卡片不收起，离开面板与卡片后按参考稿时序恢复收起态。
  **自动证据**：组件测试断言 240px、12px、三行模板，使用 fake timers 证明跨入预览会取消 close timer、离开两者 120ms 后收起，并覆盖最左 / 最右事件。
  **独立视觉复核**：必须核对卡片密度、固定横向间距、纵向跟随、跨间隙可达和关闭手感。

- [x] **[既有行为回归保护] 交互与定位失败**：目录内滚轮和方向键能浏览被折叠事件但主时间线不动；点击、Enter 或 Space 后才把原消息定位到阅读区并短暂突出；目标消失时原滚动位置不变并显示可理解反馈。
  **自动证据**：模型、组件和 OperatorConsole 测试覆盖 wheel 隔离、Arrow 浏览、Enter / Space 激活、scrollIntoView、目标失效与反馈文案。
  **独立视觉复核**：真实桌面复核键盘焦点移动、激活后的定位 / 突出和失败反馈；视觉复核不替代自动失败路径断言。

- [x] **[生产环境适配] 长会话 / 溢出**：在矮窗口打开超过容量的长会话并把阅读焦点分别移到开头、中段、末尾；展开面板不越过可用视口或 composer，当前焦点和首尾边界按规则保留，省略区两侧没有跨区虚构连线，全部隐藏事件仍可经滚轮 / 方向键到达。
  **自动证据**：纯模型参数化测试覆盖三种焦点窗口、按最大展开行高计算容量、极矮视口降级和省略边界断线；组件测试断言面板高度不超过输入可用高度。
  **独立视觉复核**：必须缩放真实桌面高度，核对不裁切、不盖 composer、省略位置和浏览连续性。

- [x] **[生产环境适配] 宽度与侧栏**：分别在一名成员、多名成员和窄窗口下展开；面板按泳道数量增长，空间不足时压缩泳道或翻转 / 约束预览；开合项目侧栏和右侧栏后目录仍属于主会话，不迁入侧栏、不挤压正文。
  **自动证据**：纯模型测试覆盖成员数与可用宽度矩阵；OperatorConsole 测试覆盖侧栏开合前后的目录父级、正文尺寸和主时间线实例稳定。
  **独立视觉复核**：必须在常规 / 窄窗口及左右侧栏组合下核对内容驱动宽度、预览碰撞策略和正文不被挤压。

- [x] **[既有行为回归保护] 主题与减弱动效**：在亮色、暗色和 `prefers-reduced-motion: reduce` 下复核；面板、描边、身份色和 hover 对比均可辨，减弱动效时宽高、节点、路径和预览即时到位，信息、焦点与定位能力不减少。
  **自动证据**：组件测试 mock `matchMedia` 并断言 motion-reduce 类 / 即时目标状态；Storybook build 覆盖明暗主题 Story 可构建。
  **独立视觉复核**：必须在真实桌面切换亮暗主题并启用减弱动态效果，核对对比度、无残留过渡和交互等价。
