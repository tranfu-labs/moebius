# Console 中的 Claude TUI 运行表面

基线：`docs/wireframes/pages/console.md#Running`。本 change 不新增路由；只在 Claude-bound active run 的既有运行块中替换实时正文承载。

```text
┌ 开发 · Claude Code · 运行中                         [中断] ┐
│ ┌─ Claude terminal ──────────────────────────────────────┐ │
│ │ ❯ Claude Code                                           │ │
│ │ 读取工作区…                                             │ │
│ │ ────────────────────────────────────────────────────── │ │
│ │ 等待下一轮                                              │ │
│ └────────────────────────────────────────────────────────┘ │
│ 最终回复会在本轮 Stop 后写入正常 Agent 正文。                │
└─────────────────────────────────────────────────────────────┘
```

状态：无 Claude TUI 时不渲染此表面；初始化或 reconnect 显示只读连接状态；hook/PTY/ transcript 任一失败时保留已有安全失败块且不把原始终端字节写进时间线。窄窗口时终端横向/纵向在自身区域滚动，页面不产生横向滚动。终端没有可聚焦的命令输入；composer 是唯一输入入口。
