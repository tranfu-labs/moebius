# 线框：separate-file-reading-modes

基线：[docs/wireframes/pages/console.md](../../../docs/wireframes/pages/console.md)。主页面右侧栏已有页面 PRD，以下只描述本次变化；冲突时以 `docs/product/pages/main-right-sidebar.md` 为准。

## pages/main-right-sidebar.md

### 项目文件：普通源码阅读

```text
┌ 项目文件 × ────────────────────────────────────────┐
│ 项目文件夹 · 当前文件                              │
│ ┌ 文件树 ───────┐ ┌ src/config.ts ───────────────┐ │
│ │ ▾ src         │ │  1 │ export const config = { │ │
│ │   config.ts ● │ │  2 │   port: 4317,           │ │
│ │   server.ts   │ │  3 │ };                       │ │
│ │ ▾ docs        │ │                               │ │
│ │   README.md   │ │ 当前源码 · 只读              │ │
│ └───────────────┘ └───────────────────────────────┘ │
└────────────────────────────────────────────────────┘
```

只有一列当前行号，不出现旧 / 新双行号、增删底色和 `+` / `−`。文件树中的改动状态可以保留，但不改变内容阅读语义。

### Markdown 裸路径：默认 Preview

```text
┌ README.md × ───────────────────────────────────────┐
│ /workspace/README.md              [Preview] [源码] │
├────────────────────────────────────────────────────┤
│ Moebius                                            │
│                                                    │
│ 本地优先的多 Agent 协作操作台。                    │
│                                                    │
│ 开发文档                                           │

```

### Markdown 显式行号：默认源码并定位

```text
┌ README.md:42 × ────────────────────────────────────┐
│ /workspace/README.md              [Preview] [源码] │
├────────────────────────────────────────────────────┤
│ 40 │ ## Development                                │
│ 41 │                                               │
│ 42 │ pnpm install                 ← 当前目标        │
│ 43 │ pnpm desktop                                  │
└────────────────────────────────────────────────────┘
```

目标行使用边框、标记或文字等非纯颜色信号突出。切到 Preview 再切回源码后，目标仍回到视野内。

### 工作区外：有界预览

```text
┌ rollout.jsonl:292 · 预览 × ────────────────────────┐
│ 预览 · 工作空间外文件                              │
│ /tmp/rollout.jsonl                                 │
│ 仅显示目标位置附近内容                             │
├────────────────────────────────────────────────────┤
│ 290 │ {"type":"response_item", ...}              │
│ 291 │ {"type":"event_msg", ...}                  │
│ 292 │ {"type":"turn_context", ...} ← 当前目标    │
│ 293 │ {"type":"event_msg", ...}                  │
└────────────────────────────────────────────────────┘
```

即使外部文件扩展名为 `.md`，也不提供 Markdown Preview；片段渲染会把不完整文档伪装成完整内容。

### 明确失败

┌ generated.bin × ───────────────────────────────────┐
│ 无法显示此文件                                     │
│ 这是二进制文件，文件阅读仅支持 UTF-8 文本。        │

大文件、无效 UTF-8、目录、不存在、不可读与预算超限使用各自原因；失败不保留上一文件内容冒充当前目标。
