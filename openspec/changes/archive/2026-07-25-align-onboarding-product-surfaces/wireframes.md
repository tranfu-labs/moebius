### 第 1 步三类环境状态

```text
ready（静态评审表面）
┌ 状态卡 ─────────────────────────────────────────────┐
│ ✓  Codex 已安装        已在这台电脑上找到      通过 │
│ ✓  Codex 可以运行      Agent 团队可以正常启动  通过 │
└─────────────────────────────────────────────────────┘

missing
┌ 错误卡 ─────────────────────────────────────────────┐
│ ×  未找到 Codex                                     │
│    在终端运行以下命令，然后重新检查。               │
│    ┌──────────────────────────────────────────┐     │
│    │ brew install codex                [复制] │     │
│    └──────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────┘

unavailable
┌ 错误卡 ─────────────────────────────────────────────┐
│ ×  Codex 暂时无法运行                               │
│    请在终端运行 codex，完成登录或按终端提示修复后， │
│    再回来重新检查。                                 │
└─────────────────────────────────────────────────────┘

固定全局 footer（两类错误相同）
┌─────────────────────────────────────────────────────┐
│                         [重新检查] [继续（灰置）]    │
└─────────────────────────────────────────────────────┘
```

- 正式 Electron 页面第二行辅助文本显示最近一次真实 `codex --version` 结果；
  PRD 字符图、独立 HTML 原型和 Storybook 等没有真实检测输入的静态表面使用上面的
  通用文案，不写示例版本号。
- 「重新检查」和灰置「继续」不属于错误卡。
- unavailable 卡内没有安装命令、复制按钮、底层路径或原始错误。

### 回看模式

```text
┌────────────────────────────────────────────────────────────┐
│ [Moebius 品牌图标] Moebius          回看引导   [退出]     │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                  第 n 步，共 4 步                          │
│                     原引导内容                             │
│                                                            │
├────────────────────────────────────────────────────────────┤
│ 第 1 步未通过：[重新检查] [继续（灰置）]                   │
│ 第 2–3 步：                 [上一步] [继续]                │
│ 第 4 步：                   [上一步] [开始使用]            │
└────────────────────────────────────────────────────────────┘
```

- 回看身份只由标题栏「回看引导 / 退出」表达。
- 「退出」与第 4 步「开始使用」都恢复进入前的 mock 主页面；第 4 步不显示
  「完成回看」。
- 首次启动不显示「退出」，第 4 步仍由「开始使用」进入带所选团队的新建对话。

### AI 调整 turn 的可观察顺序

```text
发送前                    发送后、AI 返回前             AI 返回后
┌ 方案卡 ───────┐        ┌ 方案卡·只读 ───┐           ┌ 方案卡·可确认 ┐
│ [继续聊着调整]│        │                │           │              │
└───────────────┘        └────────────────┘           └──────────────┘
                         ┌───────────────┐             ┌───────────────┐
                         │ 用户调整正文 →│             │ 用户调整正文 →│  恰好一次
                         └───────────────┘             └───────────────┘
                         ┌ AI 正在输入…  ┐             ┌ AI：已按要求  │
                         └───────────────┘             │ 调整方案。    │
                                                       └───────────────┘
```

用户气泡必须先于 typing 进入对话；mock 回复不得再次拼接用户正文。
