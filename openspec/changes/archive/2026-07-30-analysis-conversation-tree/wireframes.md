# 线框：analysis-conversation-tree

基线：`docs/wireframes/pages/console.md`。该历史线框已声明页面事实由 `docs/product/pages/main-conversation.md` 接管；以下字符图只标出本 change 的版式差异。

## pages/main-conversation.md

### 根对话·宽屏

```text
┌ 左侧栏 ─────┬ 根对话内容 ──────────────────────────────┬ 外层右侧栏 ─────────┐
│ 根对话 A  ← │ 根对话 A                  [分析] [右栏] │ [分析 A] [分析 B]   │
│ 根对话 B    │ 目录  时间线             ┌ 分析面板 ─┐ │                    │
│             │                           │ 分析 A     │ │ 当前活动兄弟标签   │
│             │                           │ 分析 B     │ │                    │
│             │ 输入框                    └────────────┘ │                    │
└─────────────┴──────────────────────────────────────────┴────────────────────┘
```

- 左侧栏不出现分析 A、分析 B。
- 面板只显示根对话 A 的直接分析子项，不显示孙辈。
- 面板和外层右侧栏由相邻但独立的开关控制。

### 根对话·窄内容区

```text
┌ 根对话内容 ───────────────────────────────┐
│ 根对话 A                   [分析] [右栏] │
│ ┌ 分析面板（覆盖层）───────────────────┐ │
│ │ 分析 A                              │ │
│ │ 分析 B                              │ │
│ └─────────────────────────────────────┘ │
│ 时间线（宽度不变，阅读位置不变）         │
│ 输入框                                  │
└─────────────────────────────────────────┘
```

### 面板状态

```text
空态             加载                 失败
┌──────────┐     ┌──────────┐        ┌──────────────┐
│ 暂无分析 │     │ 正在读取…│        │ 读取失败     │
│          │     │          │        │ [重试]       │
└──────────┘     └──────────┘        └──────────────┘
```

## pages/main-right-sidebar.md

### 分析对话自己的面板与孙辈兄弟标签

```text
┌ 主内容：根对话 A ───────────┬ 同一外层右侧栏标签组 ─────────────────────┐
│                              │ [分析 A] [分析 A-1] [完整输出]            │
│                              │ ┌ 分析 A 标题                 [分析] ┐   │
│                              │ │ 时间线       ┌ 直接子面板 ───────┐ │   │
│                              │ │              │ 分析 A-1          │ │   │
│                              │ │ 输入框       └───────────────────┘ │   │
│                              │ └────────────────────────────────────┘   │
└──────────────────────────────┴──────────────────────────────────────────┘
```

- 分析 A-1 只出现在分析 A 的面板。
- 点击后分析 A-1 成为同一外层标签条的唯一兄弟标签，不创建嵌套右侧栏。

### 跨树引用

```text
根 A / 分析 A  --点击 moebius-ref-->  预加载根 B + 根 B 标签现场
                                           │
                              成功：一次提交根 B + 目标分析标签
                              失败：保留根 A、活动标签与阅读位置
```
