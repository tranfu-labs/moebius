# 设计：adopt-home-page-design

## 方案

以设计参考 HTML 为生产页基线，只做生产接线：补齐品牌图标与产品预览资源路径，把仓库和 Releases 占位链接替换为公开地址。三个下载按钮先使用稳定的 `/releases/latest` 后备地址；内联脚本通过 GitHub Releases API 寻找最新非草稿、非预发布版本中的 `-mac-arm64.dmg` 资产，成功后统一替换为直链。

## 权衡

固定当前 `v0.1.3` DMG 能立即直下，但下一次发版后会过期；只链接 Releases 页面永远有效，但多一次点击。采用“稳定后备 + 运行时解析直链”兼顾当前直下和未来版本，API 失败时仍不会形成死链。

不把设计稿继续作为第二套生产实现；正式入口独立部署，设计参考保持不变。

## 风险

GitHub API 可能因网络或限额失败，页面会回退到 Releases 最新页。回滚只需恢复上一版 `index.html` 并移除新增预览资源；没有服务端或数据迁移。
