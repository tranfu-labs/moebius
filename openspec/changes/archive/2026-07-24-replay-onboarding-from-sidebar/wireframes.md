## pages/console.md

### 侧栏底部操作

```text
┌──────────────────────────────┐
│                              │
│       项目与对话列表         │  唯一可滚动区域
│                              │
├──────────────────────────────┤
│ ? 重新查看引导               │  固定；侧栏导航行
│ ⚙ 设置                       │  固定；现有占位入口
└──────────────────────────────┘
```

- “重新查看引导”位于“设置”之前，键盘顺序与视觉顺序一致。
- 两行均不随项目列表滚动；窗口高度不足时仍保持可达。

## pages/onboarding.md

### 回看模式

```text
┌────────────────────────────────────────────────────────────┐
│ [Moebius 品牌图标] Moebius           回看引导   [退出]    │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                  第 n 步，共 4 步                          │
│                     原引导内容                             │
│                                                            │
├────────────────────────────────────────────────────────────┤
│ · · ● ·  n / 4                    [上一步] [继续]          │
└────────────────────────────────────────────────────────────┘

第 4 步：
┌────────────────────────────────────────────────────────────┐
│ · · · ●  4 / 4                  [上一步] [完成回看]       │
└────────────────────────────────────────────────────────────┘
```

- 标题栏的“退出”始终可达，并使用 `window-no-drag` 交互区。
- 回看隐藏侧边栏和操作台视觉，但不卸载原操作台；退出或完成后恢复进入前状态和入口焦点。
- 首启模式版式保持原样，不出现“退出”或“完成回看”。
