# restore-onboarding-action-footer 版式

基线：`docs/wireframes/pages/onboarding.md`（该页面的当前产品事实已由 `docs/product/pages/onboarding.md#页面结构` 接管）。

## pages/onboarding.md

### 常规步骤

```text
┌────────────────────── 应用标题栏 ──────────────────────┐
│                                                       │
│                    第 n 步，共 4 步                   │
│                      当前步骤标题                     │
│                                                       │
│          普通内容 512px / 宽版内容 780px              │
│              超高内容只在主体中滚动                   │
│                                                       │
├──────────────── 固定底部操作 footer ─────────────────┤
│       ┌────────────── 最大 780px ──────────────┐       │
│       │                         [上一步] [继续]│       │
│       └───────────────────────────────────────┘       │
└───────────────────────────────────────────────────────┘
```

footer 只有操作按钮，不显示步骤圆点、`n / 4` 或第二套进度；相邻按钮间距为 8px，主按钮右边缘与 780px 对齐框架一致。

### AI 团队设计器

```text
┌────────────────────── 应用标题栏 ──────────────────────┐
│                                                       │
│                    第 2 步，共 4 步                   │
│                                                       │
│  [返回选团队]        AI 团队设计器                    │
│  ┌─────────────────────────────────────────────────┐  │
│  │ 设计器对话、提案和自身操作                      │  │
│  └─────────────────────────────────────────────────┘  │
│                                                       │
└───────────────────────────────────────────────────────┘
```

设计器打开时不显示全局底部 footer，关闭后恢复。

### 窄窗口 / 低窗口

```text
┌──────────────── 可滚动主体 ────────────────┐
│ 当前步骤内容                               │
│                    ↕                      │
├──────── 固定底部纯按钮 footer ────────────┤
│                         [上一步] [继续]    │
└───────────────────────────────────────────┘
```

主体独立滚动且不被 footer 覆盖；footer 随可用宽度缩小，不产生水平滚动。
