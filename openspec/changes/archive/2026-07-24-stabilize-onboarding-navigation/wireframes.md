## pages/onboarding.md

### 宽窗口

```text
                第 2 步，共 4 步
                  选择一支团队
                一句话说明当前目标

┌──────────────────────────── 780px ────────────────────────────┐
│                                                               │
│             普通步骤内容约 512px，水平居中                     │
│             宽版步骤内容可使用完整 780px                       │
│                                                               │
└───────────────────────────────────────────────────────────────┘
                              16px
                                               [上一步] [继续]│
                                                                ↑
                                                主按钮右边缘对齐
```

底部不再存在全窗口 footer、分割线、步骤圆点或 `n / 4`。标题区的“第 n 步，共 4 步”是唯一进度提示。

### 窄窗口

```text
←────────────── 可用宽度（保留页面边距） ──────────────→

┌──────────────────────────────────────────────────────┐
│                    当前步骤内容                      │
└──────────────────────────────────────────────────────┘
                         16px
                               [上一步] [继续]│
                                                ↑
                                  与内容框右边缘对齐
```

内容与操作行一起缩小、一起滚动，不使用 sticky 或悬浮覆盖。
