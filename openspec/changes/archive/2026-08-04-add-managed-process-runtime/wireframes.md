# Wireframes：add-managed-process-runtime

基线：`docs/wireframes/pages/console.md`。本 change 不增加页面或路由；只在真实主会话的 46px 应用顶栏增加条件式运行项入口，并在当前会话区域右上角增加轻量面板。归档时回流 `docs/product/pages/main-conversation.md` 的「页面结构」与「托管运行项入口与面板」，不回写旧 wireframe。

## pages/main-conversation.md

### 单个运行项

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                                      Storybook · 已就绪  [分析] [右侧栏] │
├─────────────────────────────────────────────────────────────────────────────┤
│  会话标题                                                                   │
│                                                                             │
│  时间线…                                                                    │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 运行项入口在分析面板开关之前；它与分析、右侧栏是三个独立按钮／触发区。
- 单项只显示简短 label 与状态；完整可访问名称包含「运行项、Storybook、已就绪」。
- 没有运行项时整个入口消失，不保留空 gap。

### 多个运行项与面板

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                                             2 个运行项 [分析] [右侧栏] │
├─────────────────────────────────────────────────────────────────────────────┤
│  会话标题                         ┌ 运行项 ──────────────────────────────┐ │
│                                   │ Storybook                已就绪     │ │
│  时间线…                          │ http://127.0.0.1:6006               │ │
│                                   │ [打开] [日志]                [停止] │ │
│                                   ├─────────────────────────────────────┤ │
│                                   │ Python worker            运行中     │ │
│                                   │ 无可打开地址                         │ │
│                                   │        [日志]                [停止] │ │
│                                   └─────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 面板锚定当前主会话右上角，不打开右侧栏，也不挤压时间线内容轴。
- 条目顺序稳定；状态变化只更新原条目。
- endpoint 只在存在受信任 loopback URL 时显示；无 URL 条目不出现空的「打开」。
- 面板关闭后顶栏入口继续随真实状态更新。

### 启动、异常与退出

```text
启动中                         健康异常                       已退出
┌ Storybook ────────────┐     ┌ Storybook ────────────┐     ┌ Storybook ────────────┐
│ 启动中                 │     │ 健康异常               │     │ 已退出 · signal SIGTERM │
│ 正在等待端口 6006      │     │ 端口暂时无法访问       │     │ 日志仍可查看            │
│ [日志]          [停止] │     │ [打开] [日志]   [停止] │     │ [日志] [清除已退出]     │
└────────────────────────┘     └────────────────────────┘     └────────────────────────┘
```

- 启动中不得使用已就绪文案；readiness 失败不自动重启。
- 健康异常仍允许用户打开地址自行检查，也保留日志与停止。
- 已退出不再提供停止。最后一个活动项退出后，顶栏保留 `Storybook · 已退出`（多个退出项为 `N 个已结束`），避免状态瞬间消失。
- 用户查看事实后明确激活「清除已退出」；确认成功且没有其他条目时顶栏入口和空 gap 一起消失，焦点进入下一个顶栏控件。清除失败保留条目、日志与重试说明；应用退出也会自然清空这些瞬时记录。

### 日志展开

```text
┌ Storybook · 日志 ────────────────────────────────────────────────┐
│ 前文已截断，显示最近输出。                                      │
│ 10:42:18  Local: http://127.0.0.1:6006/                          │
│ 10:42:19  ready in 842 ms                                       │
│                                                                 │
│ [重新加载]                                              [收起]   │
└─────────────────────────────────────────────────────────────────┘
```

- 日志是有限、可选择的等宽纯文本；终端控制字符不执行。
- loading、empty、failed 和 truncated 分开显示；读取失败不清空已经展示的尾部。

### 窄窗口

```text
┌──────────────────────────────────────┐
│                         [●2] [分析] │
├──────────────────────────────────────┤
│  会话标题                            │
│                     ┌ 运行项 ─────┐ │
│  时间线…            │ Storybook   │ │
│                     │ 已就绪      │ │
│                     │ [打开][日志]│ │
│                     │       [停止]│ │
│                     └─────────────┘ │
└──────────────────────────────────────┘
```

- 顶栏名称先收敛为数量图标，完整状态保留在 aria-label/title。
- 面板覆盖当前会话右上区域，不改变正文宽度、composer 位置或滚动现场；面板内部滚动。
- 键盘从入口进入条目操作，关闭后焦点回到入口。

### Kimi 工具完成但回合未结束

```text
顶栏： Storybook · 已就绪

时间线：
│ Kimi                                      耗时 01:07 │
│ 这一步没有正常结束。托管运行项仍在运行。             │
│                         [重试] [继续说话]             │
```

- 运行项状态与 Agent run 终局同时可见但互不覆盖。
- Provider timeout 不把 Storybook 改成失败或停止，也不生成空白成功回复。
