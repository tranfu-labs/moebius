# 线框：fix-onboarding-ai-builder-feedback-layout

## pages/onboarding.md

当前页面版式事实已由 `docs/product/pages/onboarding.md#第-2-步--ai-建队子流程` 接管；历史 `docs/wireframes/pages/` 中没有 onboarding 页面文件。本变更以该 PRD 字符图为基线，归档时回流同一 PRD 的「页面结构」。

```text
普通步骤（保持）                      AI 团队设计器打开（响应式例外）
┌──── 最大约 512px ────┐            ┌──────── 最大约 780px ────────┐
│ 标题 / 当前步骤内容   │            │ AI 团队设计器                 │
└───────────────────────┘            │                               │
                                     │               ┌ 用户新消息 ┐ │
                                     │               └────────────┘ │
                                     │ AI 正在输入…                  │
                                     │ ┌ 团队提案 · 4 名成员 ─────┐ │
                                     │ │ 成员一  @slug-one         │ │
                                     │ │ 成员二  @slug-two         │ │
                                     │ │ 成员三  @slug-three       │ │
                                     │ │ 成员四  @slug-four        │ │
                                     │ │ 你 → 主 Agent → … → 收尾 │ │
                                     │ └───────────────────────────┘ │
                                     │ [输入框                  ][↑] │
                                     └───────────────────────────────┘
```

交互约束：

- 用户发送后，右侧气泡先出现，再显示 AI 正在输入。
- 提案卡高度由完整内容决定，不折叠、不内嵌第二滚动区。
- 设计器对话区是唯一内部滚动区；输入框固定在设计器底部。
