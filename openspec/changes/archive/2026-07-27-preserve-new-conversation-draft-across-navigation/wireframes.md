# 线框：preserve-new-conversation-draft-across-navigation

## pages/main-conversation.md

基线：`docs/wireframes/pages/console.md`。该历史线框已明确由 `docs/product/pages/main-conversation.md#页面结构` 接管；本 change 只沿用其桌面双栏外壳，冲突时以页面 PRD 为准。

归档回流目标：`docs/product/pages/main-conversation.md#新对话草稿的生命周期`。不向已被接管的旧 Wireframe 追加新事实。

### 新对话草稿跨导航恢复

```text
时间点 A · 新对话
┌ 侧边栏 ─────────┬─────────────────────────────────────────────┐
│ ＋ 新建对话  »  │ [▱ 项目 A ▾] [独立工作空间 ⇄] [moebius/…] │
│ 项目 A           │ [◇ 开发团队 ▾]                            │
│   会话 1         │ [▧ 页面截图.png ×]                        │
│                  │ 保留这段目标…                      ＋  ↑ │
└──────────────────┴─────────────────────────────────────────────┘

              ↓ 切到会话 1（不创建新对话行）

时间点 B · 已有会话
┌ 侧边栏 ─────────┬─────────────────────────────────────────────┐
│ ＋ 新建对话     │ 会话 1                                      │
│ 项目 A          │ ……                                          │
│   会话 1     »  │                                             │
└─────────────────┴─────────────────────────────────────────────┘

              ↓ 再次点击顶部「新建对话」

时间点 C · 恢复同一草稿
┌ 侧边栏 ─────────┬─────────────────────────────────────────────┐
│ ＋ 新建对话  »  │ [▱ 项目 A ▾] [独立工作空间 ⇄] [moebius/…] │
│ 项目 A           │ [◇ 开发团队 ▾]                            │
│   会话 1         │ [▧ 页面截图.png ×]                        │
│                  │ 保留这段目标…                      ＋  ↑ │
└──────────────────┴─────────────────────────────────────────────┘
```

项目、工作空间、团队、正文与附件在 A → B → C 后保持一致；侧边栏在首条消息成功创建前始终没有该新对话的行。

### 成功消费后的下一份新对话

```text
草稿首条消息创建成功
      ↓
侧边栏出现并选中新会话
      ↓ 再次点击顶部「新建对话」
┌──────────────────────────────────────────────┐
│ [▱ 选择项目 ▾] [◇ 上次成功使用的团队 ▾]     │
│ 描述你的目标…                         ＋  ⊘ │
└──────────────────────────────────────────────┘
  选择一个项目后才能发送
```

新的顶部入口恢复项目未选定基线；已经消费的工作空间、正文与附件不带入下一份草稿。
