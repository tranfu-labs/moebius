01 / 它怎么推进

三步，从组队到验收。

01 · SETUP

挑一支团队开工。

内置团队开箱即用；想定制，一句话让 AI 按你的项目攒一支。

02 · CHAT

像发消息一样交代任务。

主 Agent 接活派工，成员之间自己交接，全程在同一条时间线里看得见；什么时候该问你、什么时候直接跑，按你项目里的规矩来。

03 · REVIEW

结果落在一张变更清单上。

本轮动了哪些文件、每个文件改了什么，逐条 diff 摆在你面前，看完再定下一步。

02 / 开工条件

开源免注册，
交出你的第一个任务。

你需要的只有两样：一台 Mac，以及可用的 Codex CLI 或 Claude CLI。打开“终端”，任选一条版本命令；能返回版本号，就可以开始。

START COORDINATE / 02.0MAC + CODEX CLI / CLAUDE CLI

这样确认命令能返回版本号

$ codex --version

› 返回版本号 = 可以使用

$ claude --version

  • 免费开源，代码公开可查
  • 不用注册，不填密码，也不收任何密钥
  • Codex CLI 或 Claude CLI，任一即可
  • 任务在你的电脑上跑，用的是本机 CLI
  • 额度就是你平时用的那一笔，不另算
  • Moebius 本身不收费，也不加价
